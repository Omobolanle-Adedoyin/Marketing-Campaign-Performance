# Marketing-Campaign-Performance

## Project Overview

This project analyzes marketing campaign data to evaluate campaign performance, customer responses, and factors influencing marketing outcomes.

The analysis was carried out using Excel, SQL, and Power BI to clean, analyze, query, and visualize the data and generate actionable business insights.

## Tools Used

* Microsoft Excel — Data cleaning, preparation, KPIs, PivotTables, and exploratory analysis
* SQL Server — Data querying, analysis, and extracting campaign insights
* Power BI — Interactive dashboard and data visualization

## Project Objectives

* Evaluate marketing campaign performance
* Understand customer responses to campaigns
* Identify high-performing campaigns and channels
* Analyze customer demographics and behavior
* Identify patterns that can support better marketing decisions

## Analysis Performed

* Data cleaning and preparation in Excel
* KPI development
* Customer and campaign analysis
* SQL-based data analysis
* Campaign performance comparison
* Customer response analysis
* PivotTable analysis
* Interactive Power BI dashboard

## Key Metrics

The analysis focuses on relevant marketing performance indicators, including:

* Total Customers
* Campaign Responses
* Response Rate
* Campaign Performance
* Customer Engagement
* Performance by Channel

## Dashboard

The Power BI dashboard provides an interactive view of campaign performance and customer behavior, allowing users to explore the data using relevant filters and visualizations.

## Project Files

* Excel Workbook — Raw data, cleaned data, KPIs, and analysis
* SQL File — SQL queries used for campaign analysis
* Power BI Dashboard — Interactive marketing campaign dashboard
* Dashboard Screenshot — Preview of the final dashboard

## Key Insights & Recommendations

The analysis highlights patterns in customer responses and campaign performance, helping identify successful campaigns, stronger customer segments, and areas where marketing strategies can be improved.

Recommendations include focusing resources on better-performing campaigns, improving customer targeting, reviewing underperforming channels, and using customer behavior to improve future campaigns.

## Conclusion

This project demonstrates the use of Excel, SQL, and Power BI to transform marketing campaign data into meaningful insights that can support data-driven marketing decisions.
